# T6. Generar imagen de arranque con FSBL y BOOT.bin

En esta tarea preparé el flujo de arranque de la ZedBoard a partir del hardware exportado desde Vivado. Primero generé una plataforma Vitis desde el `XSA` final y, sobre ella, construí el `FSBL` mediante `xsct` para evitar depender de pasos manuales en la interfaz gráfica.

El `FSBL` final quedó congelado en `artifacts/boot/fsbl.elf` y se generó a partir del mismo hardware que ya estaba cerrando el proyecto en Vivado. Para dejar la tarea reproducible, mantuve un script específico para crear el `FSBL` y otro para ejecutar `bootgen`.

Después empaqueté el `BOOT.bin` final usando tres entradas trazables del proyecto: `fsbl.elf`, el bitstream `tfg_zedboard_bd_wrapper.bit` y `u-boot.elf` generado por Buildroot. El fichero intermedio `tfg_zedboard_boot.bif` quedó guardado como evidencia del orden de empaquetado usado por `bootgen`.

Con esto, `T6` queda cerrada. El resultado final de la tarea es `artifacts/boot/BOOT.bin`, listo para utilizarse en la partición de arranque de la tarjeta SD junto con el resto de artefactos Linux.
