# T6. Generar imagen de arranque con FSBL y BOOT.bin

En esta tarea preparé el flujo de arranque de la ZedBoard a partir del hardware exportado desde Vivado. Primero generé una plataforma Vitis desde el `XSA` final y, sobre ella, construí el `FSBL` mediante `xsct` para evitar depender de pasos manuales en la interfaz gráfica.

El `FSBL` final quedó congelado en `artifacts/boot/fsbl.elf` y se generó a partir del mismo hardware que ya estaba cerrando el proyecto en Vivado. Para dejar la tarea reproducible, mantuve un script específico para crear el `FSBL` y otro para ejecutar `bootgen`.

Después empaqueté el `BOOT.bin` usando tres entradas trazables del proyecto: `fsbl.elf`, el bitstream `tfg_zedboard_bd_wrapper.bit` y `u-boot.elf` generado por Buildroot. El fichero intermedio `tfg_zedboard_boot.bif` quedó guardado como evidencia del orden de empaquetado usado por `bootgen`.

Con esto, `T6` queda cerrada a nivel de generación de `FSBL` y empaquetado con `bootgen`. Durante la validación posterior se comprobó que el flujo activo estable de la SD no será este `BOOT.bin`, sino el arranque `U-Boot SPL` generado por Buildroot. Por tanto, `artifacts/boot/BOOT.bin` se conserva como artefacto de diagnóstico y trazabilidad del flujo FSBL.
