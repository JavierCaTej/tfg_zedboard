# T1. Preparar el entorno host y confirmar soporte de herramientas

En esta tarea verifiqué el entorno host y dejé constancia de que el equipo de trabajo es válido para continuar con Vivado, Vitis y Buildroot. Registré la versión real de Ubuntu, el kernel, el espacio libre disponible y las dependencias mínimas de Buildroot.

También confirmé el uso de la consola serie como vía de depuración del arranque y asumí la ausencia de JTAG como una limitación documentada, no como un bloqueo del MVP. Con esto dejé cerradas las comprobaciones básicas del host antes de pasar al diseño del periférico.
