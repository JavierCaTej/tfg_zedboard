# T4. Crear el proyecto en Vivado y construir el Block Design base

En esta tarea empecé la integración del periférico dentro del sistema Zynq en Vivado. Creé el proyecto `tfg_zedboard`, añadí el repositorio local de IPs, comprobé que `tfg_axi_lite_regs` aparece en el catálogo y construí el Block Design `tfg_zedboard_bd` a partir de `Zynq7 Processing System`.

Después apliqué el preset correcto de la ZedBoard, habilité `M_AXI_GP0` y `FCLK_CLK0` a `100 MHz`, añadí `proc_sys_reset`, instancié el IP y conecté el camino PS maestro -> interconnect -> esclavo AXI4-Lite. También fijé en `Address Editor` la dirección base `0x40000000` con rango `4K`, validé el diseño sin warnings críticos y generé el wrapper HDL del Block Design.
